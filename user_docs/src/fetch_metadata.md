# Fetch Metadata

1. Run EpiKodi.
2. Open the media detail view for the item you want to update.
3. Click **Fetch metadata** under the poster.

What happens:

- EpiKodi attempts to retrieve additional metadata (title, description, poster, year, etc.) from configured sources.
- Retrieved metadata is stored locally and reflected in the UI.

Tips:

- If automatic fetch fails, try renaming the file to a common naming convention (e.g., `Movie.Title (Year).ext`).
- Check network connectivity if remote lookup is used.
