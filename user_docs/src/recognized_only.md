# Show Only Recognized Media

1. Run EpiKodi.
2. Under the search text field, click the **Recognized** checkbox.

What happens:

- The library filters to show only media items that EpiKodi successfully recognized (those with known metadata).
- This helps surface well-identified items and hides unidentified files.

Tips:

- Use this filter to find items that may need metadata improvements or to focus on fully catalogued content.
