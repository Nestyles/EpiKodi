# Scan a Directory

1. Run EpiKodi.
2. Click on **Settings**.
3. Click on **Pick Directory**.
4. Use the file picker to select the directory you want to scan.
5. Click **Scan Directory**.

What happens:

- All media files inside the selected directory are scanned recursively.
- Files are classified by type (Videos, Audio, Images).
- EpiKodi extracts posters and separates descriptions/metadata when available.
- Scanning progress and any errors are shown in the UI.

Tips:

- For large collections, scanning may take several minutes.
- Ensure the app has permission to read the selected folder.
