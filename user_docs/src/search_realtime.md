# Search in Real Time by Title

1. Run EpiKodi.
2. Click on the search-by-title text field.
3. Type the media name.

What happens:

- Search results update in real time as you type, matching titles in the library.
- Partial matches and case-insensitive matches are supported (depending on configuration).

Tips:

- Use short keywords to get broader matches.
- If results are missing, ensure the library has been scanned and metadata is up to date.
