# Select a Media

1. Run EpiKodi.
2. Click on one of your media items in the library.

What happens:

- The media detail view opens showing the description, poster/artwork and playback controls.
- From this view you can play the media or fetch/update its metadata.

Tips:

- Use the media list or search to find items quickly.
- Click the poster to open the detail view if the list shows a compact layout.
