# Watch a Video

1. Run EpiKodi.
2. Click on a video in the library or search results.
3. Click **Play**.

What happens:

- The integrated player opens with playback controls (play/pause, seek, volume).
- Video plays inside the application window.

Tips:

- Use keyboard shortcuts (if available) for play/pause and seeking.
- Adjust volume and playback speed via the player controls.
